# Review workflow v1 archive

This directory preserves the benchmark and review state before the risk-based
semantic screening workflow was introduced.

- `canonical_tasks.jsonl`: unchanged 40-task canonical snapshot
- `semantic_review.csv`: original one-row-per-task sequential review queue
- `validation_report.json`: original 649-check mechanical validation report

No human decisions had been recorded. The active canonical task file was not
modified when the new review workflow was introduced.
